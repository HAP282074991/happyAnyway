# 微信验证能力

- npm run verify 执行网络边界正反回归、ESLint、TypeScript 类型检查、编译、页面资源和文档链接检查。
- 网络限制覆盖 platform 外 wx.request、字符串计算属性及可选链直接引用；platform 封装合法。复杂动态别名和运行时计算仍需人工审核。
- 骨架包含原生首页和基础 app/project 配置；依赖由 package-lock.json 锁定。
- 根 CI 调用上述入口；远端启用和合并保护应单独核实。
- 开发者工具、真机、实际 AppID、业务请求联调和契约兼容按开发任务验证，本地静态检查不能替代。

当前阶段以根 docs/project-state.json 为准。架构阶段不创建未确认业务；实际验证结果保存在根任务证据，架构验收后清理筹备历史。

## 规范与自动检查边界

[开发](rules/development.md)、[测试](rules/testing.md)、[审查](rules/review.md)规则已作为工程入口的专项资料；规则文件存在不表示所有要求已由工具执行。

现有自动检查覆盖前述网络引用、类型、编译、基础资源和链接。页面状态、异步竞态、资源清理、接口语义、会话与缓存、日志注释和适用设备交互仍需按任务人工审核或补充相应测试。尚未实现的业务和封装不记为已交付能力。
