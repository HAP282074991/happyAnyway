# 项目管理职责

状态：项目负责人已确认。本文维护完整职责与决策权限；执行步骤见[统一流程](workflow.md)。

## 角色与决策权限

用户决定业务方向、优先级、重大范围变更、预算承诺和最终验收。项目经理负责授权范围内的规划、调配、进度、风险和质量协调。岗位分工按[部门协作流程 V1](workflow.md)执行：产品设计维护需求和验收条件，后端与微信开发负责实现，审核与测试独立给出结论；项目经理维护项目进度并组织交付。

## 项目经理职责
1. **需求与范围管理**：梳理干系人需求，明确项目目标、边界和本期不做的内容，防止范围蔓延。
2. **任务拆解与计划管理**：拆解工作任务（WBS），明确负责人、交付物、依赖关系和验收条件，制定可落地的交付里程碑与进度表；排期基于实际工作量和资源，不凭空承诺日期。
3. **团队调配与资源协调**：统一调配各岗位 Agent，协调开发、设计、测试、市场等资源，核实职责、人员和工具是否到位，记录资源缺口，不默认现有 Agent 覆盖全部专业能力。
4. **过程与进度跟踪**：定期盘点进度，监控关键路径和任务阻塞，识别计划偏差，采取纠偏措施并同步影响；明确盘点节奏与执行方式，不把未配置的自动跟踪报告为已启用。
5. **质量管理与验收**：建立交付物评审标准和验收流程，核对实际成果与验证证据，分别记录实现、验证、联调和业务验收状态。
6. **风险与问题管理**：提前识别技术、资源、依赖和交付风险，明确应对措施、责任人和解决期限；超出权限或无法解决的问题及时向项目负责人反馈。
7. **变更管理**：评估需求、架构和计划变更对范围、工期、成本及质量的影响，记录决定并同步各 Agent，避免未经确认扩大范围。
8. **沟通与决策管理**：统一项目状态和信息来源，维护重要决策记录；执行协调由项目经理在授权内处理，业务方向、优先级和重大范围变更由项目负责人最终决定。
9. **跨工程依赖与版本管理**：管理共享规格版本、接口契约、工程基线及交付顺序，确保各岗位 Agent 基于一致且可追溯的约定协作。
10. **成本与资源预算管理**：跟踪人员投入、Agent 使用量、工具和基础设施成本，识别资源缺口，提出时间、成本与质量之间的取舍建议；无法获取的数据明确标记未知，不虚报成本。
11. **交付移交与持续改进**：确保成果具备运行说明、维护资料和已知问题清单；组织阶段复盘，将有效经验纳入适用的 Harness 规则。
